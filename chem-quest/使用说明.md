# 化学闯关 · 使用说明

人教版九年级化学上册 **全部七个单元** 知识点覆盖。

## 怎么打开

**电脑**：双击 `index.html`，浏览器打开即可。
**手机**：把 `化学闯关_可发微信.html` 通过微信发过去，手机浏览器打开即玩，**离线可用**，进度存在本机。

## 玩法

- 每局 **10 题**，约 1 分钟，随时可退出
- 首页可选 **第一至第七单元 / 基础复习 / 全部**
- 点任一类别卡片 → **进入该类别专项练习**（再点一次退出）
- 答对得分，**连击**有加成；答错立刻显示正确答案和解析

## 掌握规则（重要）

> **答对一次即记为「已掌握」，答错则撤销。**

- 已掌握的题会**自动退出练习池**，不再重复抽取
- 类别卡显示 `已掌握 / 总题数`，下方「待练 N 题」是还没掌握的
- 想重练已掌握的题：点 **「重置掌握记录」**（只重置当前范围，错题本不受影响）

**为什么这样设计**：这是背诵练习工具，答对即过、答错即回炉。担心"蒙对"的话，用「重置掌握记录」把题目加回来重练即可。

## 题库是怎么来的

**全部题目从人教版九年级化学上册课本原文逐条抽取，每一道题的答案都能在原文中直接找到依据。**

出题铁律：

1. 原文没写的，不出
2. 表格数字逐条照抄，不"大致"
3. 原文中是空白表格或图示（正文没给结论）的，**不出题**
4. 干扰项取学生真实易混点（Cu/Ca/Cl/C、Co/CO、质子数/中子数、混合物/化合物等）

**因原文缺失而未出题的典型部分**（各单元均有记录）：

- 第一单元：课本没有"过滤与蒸发"操作表述，未出该类题
- 第二单元：红磷测氧气只写"液面上升"，未给"约占 1/5"，故不考体积分数
- 第五单元：质量守恒实验表 m₁/m₂ 全空，只考装置操作，不考数值结论
- 第六单元：CO₂ 性质表整表留空，未据表出题
- 第七单元：蜡烛燃烧实验表、灭火原理对照表全空，未出题

各单元的图片类信息（装置图、示意图）正文未复述结论的，一律不出题。

## 修改题库

1. 编辑 `bank/unit1.json` ~ `unit7.json`（格式：`{"cat","q","a","opts","why"}`）
2. 运行 `node build.js`（会校验结构并重新生成）
3. 生成的 `index.html` 另存为 `化学闯关_可发微信.html`

课本原文（供核对）在 `_src/` 目录：第一~七单元各一个 .md 文件。

## 三大机制

1. **答对即掌握** — 会的题退场，只练不会的，效率最高
2. **随时重置** — 蒙对的、想复习的，一键加回来
3. **主动回忆** — 问"氢的符号是？"而不是给"H=氢"，逼脑子调取
