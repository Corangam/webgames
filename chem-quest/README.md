# 化学闯关 · 九年级化学上册

人教版九年级化学上册知识点背诵练习游戏。**859 道题，覆盖全部七个单元。**

👉 **在线玩**：https://corangam.github.io/webgames/chem-quest/

## 特点

- **每局 10 题，约 1 分钟**，随时可退出，适合零碎时间
- **答对一次即记为「已掌握」**，答错的题会撤销掌握状态并很快再出现
- 已掌握的题自动退出练习池，只练不会的
- 支持**按单元 + 按知识点类别**专项练习
- 进度存在浏览器本地，关掉再开还在
- **单文件、零依赖、离线可用**，手机浏览器直接打开即可

## 玩法

1. 首页选范围：第一至第七单元 / 基础练习 / 全部
2. 点任一类别卡片 → 进入该类别**专项练习**
3. 答对自动进入下一题（停 1 秒让你确认），答错手动点「下一题」
4. 想重练已掌握的题 → 点「重置掌握记录」

## 出题原则

**所有题目从课本原文逐条抽取，每一道题的答案都能在原文中找到直接依据。**

1. 原文没写的，不出题
2. 表格数字逐条照抄，不"大致"
3. 原文中是空白表格或图示（正文没给结论）的，**不出题**
4. 干扰项取学生真实易混点（Cu/Ca/Cl/C、Co/CO、质子数/中子数、混合物/化合物等）

因课本原文缺省而未出题的部分（举例）：

- 第一单元课本没有「过滤与蒸发」的操作表述 → 不出该类题
- 第二单元红磷测氧气只写「液面上升」，未给「约占 1/5」→ 不考体积分数
- 第五单元质量守恒实验表 m₁/m₂ 全空 → 只考装置操作，不考数值结论
- 第六单元 CO₂ 性质表整表留空 → 不据表出题
- 第七单元蜡烛燃烧实验表、灭火原理对照表全空 → 不出题
